What landed
-----------
End-to-end Maude implementation of `pythonlite` — a substantial Python
subset — as a CS522-style big-step / Kahn operational semantics, plus
a Python source → Maude AST parser, plus a CPython-vs-Maude
differential test harness.

10 iterative add-feature → re-run-diff-harness cycles:

  0: int / bool / arith / cmp / and-or-not / assign / print / if /
     while / `;`                                          (7 / 7)
  1: strings (literal, +, len, *), polymorphic truthy     (11 / 11)
  2: lists (literal, [i], len, +, *, .append, [i]=v);
     Outcome=Value sort                                   (16 / 16)
  3: for-loops (range, over list, nested)                  (19 / 19)
  4: augmented assignment (+=, -=, *=, //=, %=)            (20 / 20)
  5: functions: def / return / callExp / callStmt;
     Outcome ⊕ ret(V)                                     (22 / 22)
  6: lexical-scope CLOSURES + recursion + higher-order     (25 / 25)
  7: EXCEPTIONS: raise / try-except; Outcome ⊕ raised(V)   (27 / 27)
  8: tuples + multi-assign / unpacking (a, b = b, a swap)  (29 / 29)
  9: DICTS: {k:v, ...}, d[k], d[k]=v, len(d), k in d        (31 / 31)
 10: LAMBDAS (anonymous closures)                          (32 / 32)

Final: 32 / 32 corpus programs match CPython 3.11 output
byte-for-byte.
